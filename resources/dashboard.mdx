Payven iki web paneli sunar:

| Panel | Kim kullanır | Ne için |
|---|---|---|
| **Konsol** (Backoffice) | Organizasyon (tenant) yöneticileri ve operatörleri | Tüm bayilerin işlemleri, konfigürasyon, kullanıcı ve plan yönetimi |
| **İşyeri Paneli** | Bayi (işletme) yöneticisi ve çalışanları | Kendi işletmesinin ödemeleri, ödeme linkleri, hakedişi, entegrasyon bilgileri |

[**Konsola Git →**](https://dashboard.payven.com.tr)

## Konsol

| Kategori | Ekranlar |
|---|---|
| **İşlemler** | İşlem listesi, detay ve zaman çizgisi, iade/iptal talepleri, dışa aktarma |
| **Bayiler** | Bayi listesi, alt bayiler, başvurular, toplu bayi yükleme, canlıya geçiş talepleri |
| **Konnektörler** | Banka katalogu ve konfigürasyonları (kimlik bilgisi, bayi profilleri), hata kodu eşlemeleri |
| **Akıllı Yönlendirme** | Basit ve gelişmiş yönlendirme kuralları |
| **Mutabakat** | Mutabakat oturumları, tutarsızlık çözümü |
| **API Anahtarları** | Anahtar oluşturma (test/canlı), izinli IP, rotasyon |
| **Fraud** | Kural, kara liste ve uyarılar |
| **İzleme** | API istek kayıtları, işlem izi, banka sağlık paneli |
| **Kullanıcılar ve roller** | Kullanıcı, rol ve izin yönetimi |
| **Plan ve Kullanım** | Aktif plan ve kotalar |

Kullanılabilen ekranlar kurulu ürünlere ve rolünüzün izinlerine göre değişir; izniniz olmayan ekran menüde görünmez.

## İşyeri Paneli

| Kategori | Ekranlar |
|---|---|
| **Ödemeler** | Ödemeler, iadeler, itirazlar, abonelikler, ödeme linkleri, yeni ödeme |
| **Mağaza** | Ürünler, indirim kodları, ödeme sayfası ayarları |
| **Hakediş** | Bakiye, hareketler, ekstreler, hesaba aktarım |
| **Payven Kart** | Kart başvurusu, hareketler, nakde dönüştürme |
| **Faturalar** | e-Fatura kesimi, gelen belgeler, otomasyon |
| **Ayarlar › Entegrasyon** | Test/canlı durumu, API anahtarları, entegrasyon bilgileri (API ve Identity adresleri), webhook adresleri, test modu, canlıya geçiş talebi, test verisini silme |
| **Ayarlar** | İşletme profili, ekip, bildirimler, tarife, güvenlik |

Panel, **Test modu** göstergesiyle işletmenin test mi canlı mı çalıştığını gösterir; test modundaki işletmede yapılan işlemler bankaya gitmez.

## Mobil uyumluluk

Paneller mobil cihazlarda kullanılabilir: kenar menü gizlenir, tablo sütunları daraltılır.

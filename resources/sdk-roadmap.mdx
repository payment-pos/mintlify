Payven, her dil için ayrı resmi SDK yerine **OpenAPI tabanlı** bir geliştirici deneyimi sunar: her ürünün şeması yayınlanır, istemciyi kendi dilinizde üretir, token yönetimini ise [Kimlik Doğrulama](/documentation/concepts/authentication#kod-ornekleri-auto-refresh) sayfasındaki hazır istemci sınıflarıyla yaparsınız.

## OpenAPI şemaları

| Ürün | Şema |
|---|---|
| Sanal POS | `https://docs.payven.com.tr/api-reference/sanal-pos/openapi.json` |
| Para Transferi | `https://docs.payven.com.tr/api-reference/transfer/openapi.json` |
| Identity | `https://docs.payven.com.tr/api-reference/identity/openapi.json` |
| Fraud | `https://docs.payven.com.tr/api-reference/fraud/openapi.json` |

Şemalar OpenAPI 3.1'dir ve `securitySchemes` tanımlıdır. [openapi-generator](https://openapi-generator.tech) ile istemci üretilebilir:

```bash
# Python
openapi-generator-cli generate \
  -i https://docs.payven.com.tr/api-reference/sanal-pos/openapi.json \
  -g python \
  -o ./payven-python

# C# (.NET)
openapi-generator-cli generate \
  -i https://docs.payven.com.tr/api-reference/sanal-pos/openapi.json \
  -g csharp \
  -o ./payven-dotnet

# Go
openapi-generator-cli generate \
  -i https://docs.payven.com.tr/api-reference/sanal-pos/openapi.json \
  -g go \
  -o ./payven-go
```

<Tip>
Üretilen istemcide `Authorization: Bearer ...` header'ını sizin yönetmeniz gerekir. Token alma (`/auth/{slug}/token`) için [Kimlik Doğrulama](/documentation/concepts/authentication#kod-ornekleri-auto-refresh) sayfasındaki sınıfı kopyalayın. İstek gövdesindeki alan adları **snake_case** ve büyük/küçük harf duyarlıdır; üretici ayarlarında özellik adı dönüşümünü kapatın ya da açıkça snake_case eşleyin.
</Tip>

## Yapay zeka asistanı bağlantısı (MCP)

Payven, Claude gibi bir yapay zeka asistanının hesabınıza bağlanıp "son bir ayın ödemelerini getir" gibi soruları yanıtlamasını sağlayan **uzak bir MCP sunucusu** sunar (Streamable HTTP). Yerelde kurulacak bir paket yoktur; asistanınızın bağlayıcı ayarlarına kurulumunuzun MCP adresi (`https://mcp.<alan-adı>`) girilir.

- **Kimlik doğrulama:** asistan OAuth ile bağlanır (PKCE). Onay ekranında hangi işletmelerin ve hangi izinlerin verileceğini siz seçersiniz; bağlantıyı panelde **Bağlı uygulamalar** ekranından istediğiniz an iptal edersiniz. Tarayıcı akışı olmayan ajanlar için API anahtarı ekranında **salt okunur ajan anahtarı** (`pvak_...`) üretilir.
- **Varsayılan salt okunurdur:** hesap bilgisi, ödeme listesi ve özetleri, iade ve cüzdan hareketleri okunur. Yazma, yalnızca onay ekranında ayrıca verdiğiniz izinle açılır (ödeme linki oluşturma, bekleyen transferi onaylama); ajan anahtarı hiçbir zaman yazamaz.
- **Test/canlı:** test ortamındaki bağlantı yalnız test verisini görür.
- Tutarlar kuruş, tarihler Türkiye saatidir; asistan bunları kullanıcıya TL ve yerel saatle sunar.

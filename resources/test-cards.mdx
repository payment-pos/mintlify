---
title: "Test Kartları"
description: "Test modunda kullanılabilen kart ve test verisi referansları."
---

Test modunda (test API anahtarı ya da test modundaki işyeri) ödemeler bankaya gitmez; Payven'in kendi simülatörü yanıt verir. Geçerli biçimde herhangi bir kart numarası başarılı sonuç üretir (örneğin `4111 1111 1111 1111`, ileri bir son kullanma tarihi, herhangi 3 haneli CVV); 3D Secure ekranında herhangi 6 haneli kod kabul edilir.

Belirli senaryoları (banka reddi, yetersiz bakiye, 3D hatası ...) denemek için **kayıtlı test kartları** kullanılır. Kartların güncel listesi İşyeri paneli › Ayarlar › Entegrasyon ekranında ve Sanal POS test kartları sayfasındadır: [Sanal POS → Test Kartları](/sanal-pos/test/test-cards).

Para Transferi için test alıcı hesapları: [Para Transferi → Test Modu ve Test Alıcıları](/para-transferi/sandbox).

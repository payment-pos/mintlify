Identity, Türkiye'deki bankaların kataloğunu sağlar. Banka kodu (TCMB), ad ve görsel bilgileri buradan çekilir. IBAN'dan banka çözümleme ([IBAN Doğrulama](/identity/validation/iban)) ve BIN'den banka çözümleme ([BIN Sorgulama](/identity/lookups/bins)) aynı kataloğa dayanır.

## Endpoint

```http
GET /api/v1/lookups/banks
```

Bearer access token gerektirir.

```bash
curl "https://identity.payven.com.tr/api/v1/lookups/banks?search_term=garanti" \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

| Query parametresi | Tip | Açıklama |
|---|---|---|
| `search_term` | string | Ad veya kodda "içerir" araması |
| `include_inactive` | bool | Pasif bankaları da getir (varsayılan `false`) |

Liste **sayfalı değildir**; eşleşen tüm bankalar düz dizi olarak tek yanıtta döner.

## Yanıt

`200 OK`:

```json
[
  {
    "id":         "8e3f5c12-...",
    "code":       "00062",
    "name":       "Türkiye Garanti Bankası",
    "swift_code": "TGBATRIS",
    "logo_url":   "https://cdn.payven.com.tr/banks/garanti.svg",
    "is_active":  true
  }
]
```

| Alan | Açıklama |
|---|---|
| `code` | **5 haneli sıfır dolgulu TCMB banka kodu** (`"00062"` Garanti, `"00015"` Vakıfbank). Payven genelinde banka kodu daima bu biçimdedir; TR IBAN'ın 5-9. karakterleriyle aynıdır |
| `name` | Banka adı |
| `swift_code`, `logo_url` | Opsiyonel |
| `is_active` | Aktiflik |

<Note>
Banka kodunu karşılaştırırken 5 haneye tamamlayın (`"62"` → `"00062"`); kısa ve uzun yazım sessizce eşleşmez. `bank_code` filtreleri (ör. BIN sorgusunda) kısa yazımı kendisi tamamlar.
</Note>

## Önbellek

Banka kataloğu nadiren değişir; istemcinizde 24 saatlik önbellek yeterlidir. Birden çok referans listesini birlikte yükleyen ekranlar için `GET /api/v1/lookups/bootstrap`, **aktif** banka, BIN (ilk 2000), il, ilçe ve MCC kayıtlarını tek yanıtta döner (`banks`, `bank_bins`, `cities`, `districts`, `mcc_codes`).

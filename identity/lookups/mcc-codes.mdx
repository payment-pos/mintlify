**MCC** (Merchant Category Code), kart endüstrisinde işyerini sektörüne göre sınıflayan 4 haneli ISO 18245 kodudur. İşyeri kaydı, banka entegrasyonları ve raporlama sektöre göre çalışır.

## Endpoint

```http
GET /api/v1/lookups/mcc-codes
```

Bearer access token gerektirir.

```bash
curl "https://identity.payven.com.tr/api/v1/lookups/mcc-codes?search_term=restoran" \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

| Query parametresi | Açıklama |
|---|---|
| `search_term` | Kod veya açıklamada "içerir" araması |
| `category` | Kategori filtresi |
| `include_inactive` | Pasif kodları da getir |

Liste **sayfalı değildir**; düz dizi döner.

## Yanıt

```json
[
  {
    "id":             "5b1f...",
    "code":           "5812",
    "description":    "Yiyecek Servisleri ve Restoranlar",
    "description_en": "Eating Places, Restaurants",
    "category":       "food",
    "is_active":      true
  }
]
```

| Alan | Açıklama |
|---|---|
| `code` | 4 haneli MCC |
| `description`, `description_en` | Türkçe / İngilizce açıklama |
| `category` | Sektör kategorisi (katalogdaki değere göre) |

## Kullanım

- **İşyeri kaydı** sırasında sektör seçimi
- **Banka entegrasyonları**: bazı bankalar MCC'yi üye işyeri kaydında ister; Payven bayi kaydındaki MCC'yi bağlayıcı (connector) kurulum formuna ön doldurur
- **Raporlama**: işlemleri sektöre göre gruplama

Katalog uygulama açılışında bir kez çekilip önbelleğe alınabilir; yıl içinde nadiren güncellenir.

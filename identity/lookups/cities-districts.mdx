İl, ilçe, vergi dairesi ve resmî tatil listeleri; işyeri onboarding'i, adres / fatura formları ve valör (iş günü) hesabı için kullanılır. Hepsi Bearer token ister ve **sayfasız düz dizi** döner.

## İller

```http
GET /api/v1/lookups/cities
```

```bash
curl "https://identity.payven.com.tr/api/v1/lookups/cities?search_term=ist" \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

```json
[
  { "id": "abc-...", "code": "34", "name": "İstanbul", "country": "TUR", "is_active": true }
]
```

| Query parametresi | Açıklama |
|---|---|
| `code` | Plaka kodu filtresi |
| `search_term` | Ad araması |
| `include_inactive` | Pasifleri de getir |

`code` plaka kodudur (`34`, `06`); ilçe ve vergi dairesi sorgularında `city_code` olarak kullanılır.

## İlçeler

```http
GET /api/v1/lookups/districts?city_code=34
```

```json
[
  { "id": "...", "city_code": "34", "name": "Kadıköy", "is_active": true }
]
```

| Query parametresi | Açıklama |
|---|---|
| `city_code` | Plaka kodu. Verilmezse tüm ilçeler döner (950+ kayıt); il seçimine göre sorgulamanız önerilir |
| `search_term`, `include_inactive` | Ad araması / pasifler |

## Vergi daireleri

```http
GET /api/v1/lookups/tax-offices?city_code=34&search_term=kadıköy
```

GİB vergi daireleri; e-Fatura alıcı / satıcı bilgisi ve işyeri vergi kaydı için kullanılır.

```json
[
  { "id": "...", "code": "...", "city_code": "34", "district_name": "Kadıköy", "name": "Kadıköy Vergi Dairesi", "is_active": true }
]
```

## Resmî tatiller

```http
GET /api/v1/lookups/public-holidays?year=2026
```

Valör ("T+1") bankacılıkta **iş günü** demektir; hafta sonu kodda hesaplanır, resmî tatiller (dini bayramlar, köprü günleri) ise ilan edilir ve bu listeden okunur.

```json
[
  { "id": "...", "date": "2026-10-29", "name": "Cumhuriyet Bayramı", "is_half_day": false, "is_active": true }
]
```

`date` saat dilimsiz tarihtir (`YYYY-MM-DD`). `year` verilmezse tüm yıllar döner. Yazma uçları (`POST`, `PUT`, `DELETE /lookups/public-holidays`) `tenant-admin` / `tenant-user` rolü ister ve yönetim araçlarına aittir.

**BIN** (Bank Identification Number), kart numarasının ilk hanelerinden oluşan aralıktır. Bu aralıklar bankayı, kart birliğini (Visa, Mastercard, Troy ...), kart tipini (kredi / banka / ön ödemeli) ve kart markasını (Bonus, Axess, World ...) tanımlar. Ödeme formunda banka logosu ve taksit seçeneklerini dinamik göstermek için kullanılır.

## Endpoint

```http
GET /api/v1/lookups/bank-bins
```

Bearer access token gerektirir.

```bash
curl "https://identity.payven.com.tr/api/v1/lookups/bank-bins?bin=454671" \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

| Query parametresi | Tip | Açıklama |
|---|---|---|
| `bin` | string | Kart numarasının başı (6-8 hane önerilir). Bu değeri kapsayan BIN aralıklarını döner |
| `bank_code` | string | Bankanın tüm aralıkları; kısa kod (`62`) 5 haneye tamamlanır |
| `card_brand` | enum | `bonus`, `axess`, `world`, `maximum`, `cardfinans`, `paraf`, `advantage`, `bankkart`, `other`, `unknown` |
| `card_type` | enum | `credit`, `debit`, `prepaid`, `unknown` |
| `schema_type` | enum | `visa`, `master_card`, `troy`, `amex`, `union_pay`, `proprietary`, `unknown` |
| `include_inactive` | bool | Pasif aralıkları da getir |

Liste **sayfalı değildir**; eşleşen tüm aralıklar düz dizi olarak döner (`bank_code`, ardından `bin_start` sırasıyla).

## Yanıt

```json
[
  {
    "id":          "abc-...",
    "bank_code":   "00062",
    "bank_name":   "Türkiye Garanti Bankası",
    "bin_start":   "45467100",
    "bin_end":     "45467199",
    "schema_type": "visa",
    "card_type":   "credit",
    "card_brand":  "bonus",
    "card_length": 16,
    "is_active":   true
  }
]
```

`bin_start` / `bin_end` **8 haneli** kanonik aralıktır (6 haneli BIN sağdan sıfır / dokuz ile tamamlanır). `card_length` bu aralıktaki kart uzunluğudur.

## Tipik kullanım: dinamik ödeme formu

Kart numarası yazılırken ilk 6 hane tamamlandığında **kendi sunucunuz üzerinden** sorgulayın (token'ı tarayıcıya vermeyin):

```javascript
app.get("/api/bin/:bin", authenticate, async (req, res) => {
  const r = await fetch(
    `${IDENTITY_BASE}/api/v1/lookups/bank-bins?bin=${req.params.bin}`,
    { headers: { Authorization: `Bearer ${await getServiceToken()}` } },
  );
  const items = await r.json();
  res.json(items[0] ?? null);
});
```

Tam kart numarasını doğrulayıp banka bilgisini de aynı çağrıda almak için [Kart Doğrulama](/identity/validation/card) ucunu kullanın.

## Kart destek matrisi

```http
GET /api/v1/lookups/bank-card-support?bank_code=00062
```

BIN tablosundan türetilen salt okunur özet: banka başına desteklenen kart birlikleri, kart tipleri, markalar ve BIN sayısı (`bank_code`, `bank_name`, `supported_schemes`, `supported_card_types`, `supported_brands`, `bin_count`). `bank_code` verilmezse tüm bankalar döner.

## BIN aralığı yönetimi

BIN tablosu platform geneli referans veridir. Yazma uçları (`POST /lookups/bank-bins`, `PUT` ve `DELETE /lookups/bank-bins/{id}`, `POST /lookups/bank-bins/import`) `tenant-admin` / `tenant-user` rolü ister ve yönetim araçlarına aittir; `DELETE` kaydı silmez, pasife alır. Entegrasyonlar tabloyu yalnız okur.

## Önbellek

BIN tablosu nadiren değişir; istemcinizde 24 saatlik önbellek önerilir.

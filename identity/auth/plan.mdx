---
title: "Plan (/me/plan)"
description: "Tenant'ınıza atanmış plan, limitleri ve plana dahil feature'lar."
---

`GET /me/plan`; aktif tenant'ın atanmış planını, plan limitlerini ve plana dahil feature'ları döner. Salt okunurdur; plan değişikliği Payven yönetiminden (satış ekibi) yapılır.

## Endpoint

```http
GET /api/v1/me/plan
```

Bearer access token gerektirir.

```bash
curl https://identity.payven.com.tr/api/v1/me/plan \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

## Yanıt

`200 OK`:

```json
{
  "plan": {
    "id":                        "abc-...",
    "code":                      "standard",
    "name":                      "Standart Plan",
    "description":               "Sanal POS + Para Transferi",
    "daily_transaction_limit":   100000,
    "monthly_transaction_limit": 3000000,
    "rate_limit_per_second":     200,
    "is_active":                 true,
    "is_default":                false,
    "sort_order":                20,
    "created":                   "2026-01-15T10:00:00.000+03:00",
    "last_modified":             "2026-03-02T09:30:00.000+03:00",
    "features": [
      {
        "id":          "11111111-...",
        "code":        "sanalpos",
        "name":        "Sanal POS",
        "description": "Kart tahsilatı, 3D Secure, iade / iptal",
        "category":    "module",
        "is_active":   true,
        "installed":   true,
        "created":     "2026-01-01T00:00:00.000+03:00",
        "last_modified": "2026-01-01T00:00:00.000+03:00"
      }
    ]
  }
}
```

| Alan | Açıklama |
|---|---|
| `plan.code`, `name`, `description` | Plan kimliği ve adı |
| `daily_transaction_limit`, `monthly_transaction_limit` | Plan düzeyinde günlük / aylık işlem limiti. Anahtar bazında [override](/identity/api-keys/create) edilebilir; anahtarın nihai değeri `effective_*` alanlarındadır |
| `rate_limit_per_second` | Saniyedeki istek limiti. Aşım `429` döner ([Rate Limiting](/documentation/concepts/rate-limiting)) |
| `is_default` | Planı olmayan tenant'ların düştüğü varsayılan plan |
| `features[]` | Plana dahil feature'lar. `category`: ürün modülleri `module`; alt özellikler (ör. `fraud.sanalpos`) ayrı kategorilerdedir. Bu ortamda kurulu olmayan ürünler listelenmez |

Planda **fiyat, para birimi veya faturalama dönemi alanı yoktur**; ticari koşullar bu uçtan okunamaz.

Tenant'a plan atanmamış ve varsayılan plan da yoksa yanıt gövdesiz döner.

## Aktif feature'ları öğrenmek

Plana dahil olan feature'ın **sizin kullanıcınız için etkin ve izinli olup olmadığını** öğrenmek için [`GET /me`](/identity/auth/me) kullanın: `features[].is_active`, `permissions` ve `enabled_feature_codes` alanları tenant + plan + rol üçlüsünden süzülmüş halde gelir.

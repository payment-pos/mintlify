title: "Anahtar Pasife Alma / Silme"

---

Bir anahtarı geçici (**pasif**) veya kalıcı olarak (**sil**) iptal edebilirsiniz. İkisinde de o anahtarla yeni token alınamaz.

## Endpoint'ler

| İşlem | Endpoint | Geri alınabilir mi? |
|---|---|---|
| Pasife al / aktive et | `PUT /api/v1/tenants/me/api-keys/{id}` (`is_active`) | Evet |
| Kalıcı sil | `DELETE /api/v1/tenants/me/api-keys/{id}` | Hayır — OAuth client kaydı da silinir |

Bayi yüzeyinde aynı uçlar `/api/v1/merchants/me/api-keys/{id}` altındadır (`merchant-admin`, yalnız kendi bayisinin anahtarı). Tenant yüzeyi `tenant-admin` rolü ister.

## Pasife alma

`PUT` **tam değiştirme** semantiğindedir: gönderilmeyen alan sıfırlanır. Mevcut kaydı `GET` ile alıp yalnız `is_active` alanını değiştirerek tamamını geri gönderin.

```bash
curl -X PUT https://identity.payven.com.tr/api/v1/tenants/me/api-keys/8e3f5c12-... \
  -H "Authorization: Bearer $PAYVEN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "display_name":  "Production — Ödeme Servisi",
    "contact_email": "ops@example.com",
    "merchant_id":   "M-IST-001",
    "features":      ["sanalpos", "para-transferi"],
    "allowed_ips":   "52.18.42.10,52.18.42.0/24",
    "expires_at":    null,
    "plan_id":       "abc-...",
    "is_active":     false
  }'
```

<Warning>
Alanları eksik göndermenin sonuçları sessizdir: `is_active` verilmezse `false` sayılır (anahtar kapanır); `features` verilmezse API kapsamı **boşalır** ve entegrasyon `401 audience_invalid` almaya başlar; `merchant_id` / `allowed_ips` / `expires_at` / limit override'ları verilmezse temizlenir. `environment` ve `kind` değiştirilemez; göndermek isterseniz mevcut değerle aynı olmalıdır. `access_level` gönderilmezse mevcut düzey korunur.
</Warning>

Pasife alma **anında etkilidir**: yeni token üretimi durur. Daha önce alınmış access token'lar süreleri (5 dk) dolana kadar geçerlidir. Geri açmak için aynı gövdeyle `"is_active": true` gönderin.

## Kalıcı silme

```bash
curl -X DELETE https://identity.payven.com.tr/api/v1/tenants/me/api-keys/8e3f5c12-... \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

`204 No Content` — gövde yok. Silmeden önce anahtarın açık oturumları da düşürülür.

<Warning>
Silme **geri alınamaz**. `client_id` yeniden üretilmez; yeni bir anahtar oluşturmanız gerekir.
</Warning>

## Ne zaman pasife alın, ne zaman silin?

| Durum | Önerilen aksiyon |
|---|---|
| Anahtarın kullanılmadığını doğrulamak istiyorsunuz | **Pasife al** — birkaç hafta izleyip silin |
| Sızıntı şüphesi | **Pasife al** (anlık etki) → [rotasyon](/identity/api-keys/rotate) veya silme |
| Geçici servis kapatılıyor | **Pasife al** |
| Entegrasyon kalıcı kaldırıldı | **Sil** |

Bunların dışında, anahtara **son kullanma tarihi** (`expires_at`) vererek otomatik kapanmasını da sağlayabilirsiniz; süresi dolan anahtar `401 api_key_expired` döner.

## Hata yanıtları

| HTTP | `code` | Anlam |
|---|---|---|
| `404` | `resource_not_found` | Anahtar bulunamadı, başka tenant / bayiye ait ya da sistem client'ı (sistem client'ları silinemez / düzenlenemez) |
| `403` | `forbidden` | Rol yetersiz |
| `422` | `api_key_environment_immutable` | `PUT`'ta `environment` mevcut değerden farklı gönderildi |
| `422` | `api_key_kind_immutable` | `PUT`'ta `kind` mevcut değerden farklı gönderildi |

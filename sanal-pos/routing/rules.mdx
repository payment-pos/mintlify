---
title: "Yönlendirme Kuralları"
description: "BIN, tutar, taksit ve kart filtrelerine göre banka konfigürasyonu seçimi."
---

Bir yönlendirme kuralı; **filtreler** (BIN, tutar, taksit, para birimi, kart markası/tipi), bir **hedef** banka konfigürasyonu ve isteğe bağlı **yedek** konfigürasyon tanımlar. Yazma uçları `CanManageRouting` (varsayılan: `tenant-admin`), okuma ve `resolve` uçları `CanViewRouting` izni ister. İki kural seti ve hangisinin kullanıldığı: [genel bakış](/sanal-pos/routing/overview).

## Gelişmiş kurallar — `/routing-rules`

```http
GET    /api/v1/routing-rules                      # Liste (sayfalı)
GET    /api/v1/routing-rules/{id}                 # Tek kural
POST   /api/v1/routing-rules                      # Yeni kural — 201, gövde: kural id (UUID)
PUT    /api/v1/routing-rules/{id}                 # Güncelleme — 204
DELETE /api/v1/routing-rules/{id}                 # Silme — 204
POST   /api/v1/routing-rules/bulk-delete          # Toplu silme
PATCH  /api/v1/routing-rules/{id}/score           # Yalnız skor alanları — 204
POST   /api/v1/routing-rules/{id}/activate        # 204
POST   /api/v1/routing-rules/{id}/deactivate      # 204
POST   /api/v1/routing-rules/resolve              # Simülasyon
```

### Kural oluşturma

```bash
curl -X POST https://vpos.payven.com.tr/api/v1/routing-rules \
  -H "Authorization: Bearer $PAYVEN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name":                         "Bonus kredi kartları",
    "priority":                     10,
    "card_bin":                     "454671",
    "card_bin_end":                 "454699",
    "min_amount":                   100,
    "max_amount":                   20000000,
    "currency":                     "TRY",
    "card_brand_filter":            "bonus",
    "card_type_filter":             "credit",
    "target_connector_config_id":   "5b2e7c10-4f11-4b7a-9d3e-0a8c1f6d2e44",
    "fallback_connector_config_id": "a91c33d2-7e50-42c8-b6a1-3d9f0e5b7c18",
    "weight":                       70,
    "cost_score":                   80,
    "daily_transaction_limit":      100000
  }'
```

### Alan referansı

| Alan | Tip | Zorunluluk | Açıklama |
|---|---|---|---|
| `name` | string | Zorunlu | En çok 100 karakter |
| `priority` | short | Zorunlu | Düşük sayı = önce; `>= 0` |
| `card_bin` | string | Opsiyonel | 6–8 haneli sayısal BIN |
| `card_bin_end` | string | Opsiyonel | Aralık sonu; verilirse `card_bin` zorunlu, aynı uzunlukta ve `card_bin`'den küçük olmamalı |
| `installment_count` | short | Opsiyonel | Verilirse taksit sayısı **birebir** eşleşmeli (`> 0`). Boş = her taksit |
| `min_amount`, `max_amount` | long (kuruş) | Opsiyonel | `0` = sınır yok. İkisi de doluysa `min_amount <= max_amount` |
| `currency` | string | Opsiyonel | ISO-4217 büyük harf (`TRY`). Boş = her para birimi |
| `card_brand_filter` | enum | Opsiyonel | Kart markası, snake_case (`bonus`, `axess`, `world`, `maximum`, `cardfinans`, `paraf`, `advantage`, `bankkart`) |
| `card_type_filter` | enum | Opsiyonel | `credit`, `debit`, `prepaid` |
| `target_connector_config_id` | UUID | Zorunlu | Birinci tercih banka konfigürasyonu |
| `fallback_connector_config_id` | UUID | Opsiyonel | Hedef geçici hata verirse denenecek konfigürasyon; hedefle aynı olamaz |
| `is_active` | bool | Opsiyonel | Varsayılan `true` |
| `weight` | short | Opsiyonel | 1–100, varsayılan 50 |
| `success_rate` | decimal | Opsiyonel | 0–100, varsayılan 100 |
| `average_response_time_ms` | int | Opsiyonel | `>= 0` |
| `cost_score` | short | Opsiyonel | 1–100, yüksek = daha ucuz; varsayılan 50 |
| `daily_transaction_limit` | int | Opsiyonel | `> 0`; günlük sayaç dolunca kural o gün pas geçilir |

`GET` yanıtlarında ek olarak `id`, `target_connector_config_name`, `fallback_connector_config_name`, `daily_transaction_count`, `composite_score`, `created`, `last_modified` bulunur.

### Sıralama ve skor

Bir kural, **tanımladığı tüm filtreler** isteği karşılıyorsa eşleşir. Eşleşenler sırayla şu ölçütlerle dizilir: (1) **özgüllük** — tanımlı filtre sayısı çok olan önce, (2) **bileşik skor** yüksek olan önce, (3) `priority` düşük olan önce.

```
bileşik_skor = weight × 0,25 + success_rate × 0,35 + yanıt_skoru × 0,20 + cost_score × 0,20
yanıt_skoru  = max(0, 100 − average_response_time_ms / 50)
```

Katsayılar varsayılan değerlerdir ve Identity Ayarlar'daki `sanalpos.routing:scoring:*` anahtarlarıyla değişir. Eşleşen kural sayısı en az aday sayısından azsa listeye kısmen eşleşen, ardından kalan aktif kurallar da eklenir.

### Simülasyon

`resolve` hangi kuralların seçileceğini gösterir; üretim trafiğini etkilemez ve salt-okunur kimlik bilgisiyle de çağrılabilir.

```bash
curl -X POST https://vpos.payven.com.tr/api/v1/routing-rules/resolve \
  -H "Authorization: Bearer $PAYVEN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "card_bin":          "454671",
    "amount":            15000,
    "installment_count": 3,
    "currency":          "TRY",
    "card_brand":        "bonus",
    "card_type":         "credit"
  }'
```

Yanıt, yürütme sırasıyla kural nesnelerinin listesidir (yukarıdaki alanlar + `composite_score`).

## Basit kurallar — `/simple-routing-rules`

Varsayılan moddur; skor alanı yoktur. Gelişmiş kurallarla aynı uç kümesine ek olarak `GET .../export` ve `GET .../export/schema` sunar.

| Alan | Tip | Açıklama |
|---|---|---|
| `name`, `priority` | string, short | Ad ve sıra |
| `bank_code` | string | Kartı çıkaran bankanın 5 haneli TCMB kodu (örn. `00062`); kart BIN'inden çözülür. Boş = tüm bankalar. BIN bankası çözülemeyen kart, bankaya sabitlenmiş kurala girmez |
| `has_installment` | bool | `true` yalnız taksitli, `false` yalnız tek çekim, boş = fark etmez |
| `min_amount`, `max_amount` | long (kuruş) | Opsiyonel |
| `currency`, `card_brand_filter`, `card_type_filter` | | Gelişmiş kurallardaki gibi |
| `target_connector_config_id`, `fallback_connector_config_id` | UUID | Hedef ve yedek |
| `is_active` | bool | Varsayılan `true` |

Bayiye özel kurallar, şirket geneli kurallardan **önce** değerlendirilir; şirket geneli kurallar yedek olarak arkasına eklenir. Bayi yalıtımı açıksa şirket geneli kurallar o bayi için hiç kullanılmaz.

## Hatalar

Hatalar [`PayvenProblemDetails`](/sanal-pos/errors/overview) zarfıyla döner: doğrulama hataları `422 validation_failed` (`param` ilk hatalı alanı gösterir), olmayan kural `404`, yetkisiz rol `403`.

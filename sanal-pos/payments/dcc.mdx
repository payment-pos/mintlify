---
title: "DCC (Dynamic Currency Conversion)"
description: "Yabancı kart sahibinin para birimi tercihini işleme kaydetme."
---

DCC (Dynamic Currency Conversion), yabancı kart sahibine tutarı kendi kart para biriminde sunma yaklaşımıdır. Payven'de bugün yalnız **müşterinin DCC tercihini işleme kaydeden** bir uç vardır; ödeme isteği her zaman `TRY` ile çalışır ve Payven yanıtta kur teklifi (`dcc_*` alanları) üretmez.

<Warning>
DCC kuru ve teklifi Payven API'sinden **dönmez**. Müşteriye göstereceğiniz alternatif tutarı ve kuru kendi anlaşmanıza göre sağlıyorsanız, kart şemasının DCC kuralları (iki seçenek sunma, varsayılan olarak yerel para birimi, kur ve marjın açıkça gösterilmesi) sizin sorumluluğunuzdadır. Bankanızla DCC kapsamını netleştirmek için [destek ekibine](/resources/support) danışın.
</Warning>

## Tercihi kaydetme

```http
POST /api/v1/payments/{transaction_id}/dcc/confirm
```

Gerekli yetki `CanManageTransactions`.

```bash
curl -X POST https://vpos.payven.com.tr/api/v1/payments/8e3f5c12-9a7b-4c8d-bc4e-2c963f66afa6/dcc/confirm \
  -H "Authorization: Bearer $PAYVEN_TOKEN" \
  -H "Idempotency-Key: order-1001-dcc-confirm" \
  -H "Content-Type: application/json" \
  -d '{
    "accept_dcc": true
  }'
```

| Alan | Tip | Zorunluluk | Açıklama |
|---|---|---|---|
| `accept_dcc` | bool | Zorunlu | `true` → müşteri kart para birimiyle ödemeyi kabul etti; `false` → ana para birimiyle devam |

Gövde bir JSON nesnesi olmalıdır; gövdesiz ya da bozuk JSON `400 invalid_request_body` döner.

### Yanıt

```json
{
  "transaction_id": "8e3f5c12-9a7b-4c8d-bc4e-2c963f66afa6",
  "status":         "authorized",
  "is_success":     true,
  "message":        "DCC onayı kaydedildi.",
  "extra_properties": {
    "accept_dcc": "true"
  }
}
```

Uç yalnızca tercihi işlemin kaydına ve geçmişine yazar:

- Bankaya istek **gitmez**, tutar ve para birimi **değişmez**.
- `status` işlemin mevcut durumunu yansıtır; durum geçişi yapılmaz.

## Hata yanıtları

| HTTP | `code` | Anlam |
|---|---|---|
| `404` | `PV_TRANSACTION_NOT_FOUND` | İşlem bulunamadı |
| `400` | `invalid_request_body` | Gövde okunamadı |

Hata yanıtı RFC 9457 problem+json formatındadır. Detay: [Hata Yönetimi](/documentation/concepts/errors).

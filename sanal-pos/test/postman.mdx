## Postman ile başlama

<Steps>
  <Step title="Koleksiyonu indirin">
    Yukarıdaki "Postman Collection" linkinden `.json` dosyasını indirin.
  </Step>
  <Step title="Postman'e import edin">
    Postman → **Import** → dosyayı sürükle-bırak.
  </Step>
  <Step title="Environment'ı import edin">
    `payven-sanalpos.postman_environment.json` dosyasını da import edip sağ üstteki
    dropdown'dan **Payven SanalPOS — Sandbox**'ı seçin. Production için aynı environment'ı
    kopyalayıp `vpos_base_url` / `identity_base_url` / `merchant_base_url` değerlerini prod adresleriyle değiştirin.
  </Step>
  <Step title="Değişkenleri doldurun">
    Environment değişkenlerine kimlik bilgilerinizi yazın:
    - `client_id`: `pvk_test_...` veya `pvk_live_...` (service-account client id)
    - `client_secret`: secret değeriniz
    - `slug`: tenant slug'ınız (örn. `payven`)
    - `identity_base_url`: `https://identity-sandbox.payven.com.tr` veya `https://identity.payven.com.tr`
    - `vpos_base_url`: `https://vpos-sandbox.payven.com.tr` veya `https://vpos.payven.com.tr`
    - `merchant_base_url`: `https://merchant-sandbox.payven.com.tr` veya `https://merchant.payven.com.tr` (İşyeri API'si — webhook uçları ve olaylar; API anahtarının `merchant` kapsamı seçili olmalı)
  </Step>
  <Step title="Token alın (otomatik)">
    Koleksiyonun **Pre-request Script**'i, `access_token` boşsa veya süresi dolmak üzereyse
    `client_id` + `client_secret` ile Identity'den token alıp `{{access_token}}` ve
    `{{token_expires_at}}` değişkenlerine yazar. Ayrıca her POST isteğine `Idempotency-Key`
    ekler. `.http` dosyasında script çalışmaz — orada **Auth › Token Al** isteğini bir kez
    çalıştırıp dönen değeri `@access_token` satırına yapıştırın.
  </Step>
  <Step title="Bir isteği gönderin">
    **Odemeler (Payments)** klasöründeki **Non-3D Odeme (Sale)** isteğini açın ve **Send** edin.
  </Step>
</Steps>

## Koleksiyon içeriği

| Klasör | İstek | İçerik |
|---|---:|---|
| Auth | 6 | Token (client_credentials), login, OTP doğrula/tekrar gönder, refresh |
| Bayi Yönetimi (Identity) | 6 | Bayi oluştur, listele, detay, güncelle |
| Connector Konfigleri | 2 | Konfigürasyon oluştur, listele |
| Bayi Banka Profilleri | 5 | Profil tanımlama ve yönetimi |
| Ödemeler (Payments) | 8 | Non-3D sale, iade, iptal, capture, sipariş linki |
| 3D Secure | 3 | Init, manuel complete, sonuç |
| Hosted Checkout | 5 | Session oluştur, ödeme yöntemleri, öde, durum |
| Recurring (Abonelik) | 7 | Plan oluştur/iptal, taksit iptal/güncelle, kart vade güncelle |
| İşlemler (Transactions) | 5 | Liste, detay, geçmiş, CSV export |
| Webhook Uçları (İşyeri API) | 14 | Uç CRUD, aç/kapat, sır yenileme, deneme olayı, teslimler/denemeler/yeniden deneme, olay tipleri, olay listesi |

Toplam **61 istek**.

<Note>
**Idempotency-Key.** Ödeme, iade, iptal, capture, recurring ve checkout session
isteklerinde koleksiyon otomatik olarak `Idempotency-Key: {{$guid}}` gönderir. Aynı
anahtarla tekrar gönderim ilk yanıtı döndürür — ağ hatasında tekrar denemek çift çekim
yapmaz. `payments` için anahtar **1 gün** saklanır. Kendi entegrasyonunuzda da bu
başlığı gönderin.
</Note>

## Otomasyon ile değişken aktarma

Postman içinde "Pre-request Script" ve "Tests" bölümleri kullanılarak istekler arası değer paylaşımı yapılır:

```javascript
// Tests bölümünden — transaction_id'yi sonraki isteğe taşımak
const response = pm.response.json();
if (response.transaction_id) {
  pm.environment.set("last_transaction_id", response.transaction_id);
}
```

Sonraki istekte `{{last_transaction_id}}` ile kullanın.

```javascript
// Pre-request script — token cache + auto-refresh
const expiry = parseInt(pm.environment.get("token_expires_at") || "0", 10);
if (Date.now() >= expiry - 60_000) {
  pm.sendRequest({
    url: pm.environment.get("identity_base_url")
       + "/api/v1/auth/" + pm.environment.get("slug") + "/token",
    method: "POST",
    header: { "Content-Type": "application/json" },
    body: { mode: "raw", raw: JSON.stringify({
      client_id:     pm.environment.get("client_id"),
      client_secret: pm.environment.get("client_secret"),
    })},
  }, (err, res) => {
    const data = res.json();
    pm.environment.set("access_token", data.access_token);
    pm.environment.set("token_expires_at", String(Date.now() + data.expires_in * 1000));
  });
}
```

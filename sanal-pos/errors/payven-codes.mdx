---

Bu sayfa Sanal POS'un `code` değerlerini ve HTTP durumlarını listeler. Kodlar hata yanıtında **katalogdaki haliyle** döner (`PV_` önekli, öneksiz operasyon kodu veya snake_case). HTTP durumu koda göre sabittir: aynı durum her uçta aynı `code` ve statüyle döner. Banka tarafından gelen ham kod ayrıca `provider_error_code` alanında taşınır — bkz. [Banka Yanıt Kodları](/sanal-pos/errors/bank-codes). Zarf yapısı için: [Genel Bakış](/sanal-pos/errors/overview).

<Note>
Tablolardaki HTTP durumu katalogdaki **varsayılandır**. Bankanın yanıtından üretilen kodlarda (red, sistem hatası, zaman aşımı) durum, ilgili banka kodunun kayıtlı önerisinden gelir: çoğu ret `402`, kart verisi hataları `400`, güvenlik retleri `403`, geçici banka hataları `503`/`504` olabilir. İstek doğrulama ve iş kuralı hataları tablodaki durumla döner. Karar için daima `code` alanını kullanın.
</Note>

| `PV_UNKNOWN` | 422 | Eşlenmemiş hata — `correlation_id` ile destek talebi açın |

<Note>
**Kart numarası doğrulaması kapatılabilir.** Varsayılan olarak Payven, kartı bankaya göndermeden önce numara uzunluğunu ve Luhn kontrolünü doğrular; geçersizse `PV_INVALID_CARD_NUMBER` döner. Kart kontrolünü kendi tarafında yapan bayiler için bu doğrulama kapatılabilir — bu durumda kart olduğu gibi bankaya gider ve kararı banka verir (yanıtta Payven kodu yerine bankanın kendi kodu görünür). Ayar bayi veya tenant bazında yönetilir; talep için müşteri başarısı ekibine ulaşın.

Kapalıyken de reddedilenler: **boş** ve **maskeli** kart numarası. Son kullanma tarihi ve CVV kontrolleri bu ayardan etkilenmez.
</Note>

## Genel / HTTP kodları

Aşağıdaki kodlar ortak HTTP altyapısı tarafından üretilir; spesifik bir kod yoksa durum koduna göre kullanılır. Bu kodlar **snake_case** formatındadır.

| HTTP | `code` | Anlam |
|---|---|---|
| `400` | `bad_request` | Genel istek hatası |
| `401` | `unauthorized` | Token eksik / geçersiz / süresi dolmuş |
| `403` | `forbidden` | Yetki yok |
| `404` | `resource_not_found` | Kaynak bulunamadı |
| `405` | `method_not_allowed` | Bu path için HTTP metodu desteklenmiyor |
| `409` | `conflict` | Genel çakışma |
| `409` | `invalid_state` | Kaynak bu işlem için uygun durumda değil |
| `409` | `idempotency_key_in_use` | `Idempotency-Key` daha önce farklı gövdeyle kullanılmış |
| `409` | `idempotency_request_in_progress` | Aynı anahtarlı ilk istek hâlâ işleniyor; `Retry-After` sonrası tekrar edin |
| `415` | `unsupported_media_type` | `Content-Type` desteklenmiyor |
| `422` | `validation_failed` | Doğrulama kuralı ihlali (`errors` alanında alan bazlı detay) |
| `429` | `rate_limit_exceeded` | İstek limiti aşıldı |
| `500` | `internal_server_error` | Sunucu hatası |
| `503` | `service_unavailable` | Servis geçici olarak kullanılamıyor |
| `504` | `gateway_timeout` | Alt servis zaman aşımı |

## Bilinmeyen kod

`PV_UNKNOWN` — bankadan gelen kod Payven eşleme tablosunda yok. Bu durumlarda ham banka kodu `provider_error_code` alanında bulunur. Lütfen `correlation_id` ile birlikte [destek ekibimize](/resources/support) yazın — eşleme tablosunu güncelleyebiliriz.

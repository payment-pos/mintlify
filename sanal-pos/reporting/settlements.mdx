Sanal POS Hakediş (settlement) kayıtları **Cüzdan modülünde** tutulur ve oradaki `/settlements` uçlarından okunur; Sanal POS API'sinin kendi `/settlements` ucu yoktur. Hakediş, bayinin "param ne zaman, ne kadar, neden bu kadar" sorusunun cevabıdır: bir işlem gününün tahsilatları, iadeleri ve kesintileri **ödeme günü** (valör) bazında tek satırda toplanır.

<Note>
Bu uçlar Cüzdan modülü kurulu olan ortamlarda bulunur ve `CanViewBalance` izni ister. Bayi kapsamı `X-Merchant-Id` / `X-External-Merchant-Id` başlığından gelir; şirket kullanıcısı `merchant_id` filtresini kullanabilir.
</Note>

## Uçlar

```http
GET    /api/v1/settlements                        # Liste (ödeme gününe göre, yeniden eskiye)
GET    /api/v1/settlements/{id}                   # Tek hakediş
GET    /api/v1/settlements/{id}/transactions      # Hakedişi oluşturan hareketler (sayfalı)
GET    /api/v1/settlements/stats                  # Özet şerit
GET    /api/v1/settlements/export                 # CSV (scope=page|all)
GET    /api/v1/settlements/export/schema          # Dışa aktarma kolon şeması
```

Liste filtreleri: `merchant_id`, `status`, `currency`, `start_date`, `end_date` (`+03:00`), `page`, `page_size`.

## Hakediş nesnesi

```json
{
  "id":                      "8e3f5c12-9a7b-4c8d-bc4e-2c963f66afa6",
  "payout_date":             "2026-10-16T00:00:00.000+03:00",
  "period_date":             "2026-10-15T00:00:00.000+03:00",
  "status":                  "confirmed",
  "currency":                "TRY",
  "gross_amount":            18743500,
  "refund_amount":           235000,
  "credit_card_commission":  520000,
  "debit_card_commission":   80000,
  "other_commission":        0,
  "installment_fee":         120000,
  "chargeback_deduction":    0,
  "subscription_fee":        0,
  "net_amount":              17788500,
  "paid_amount":             0,
  "unpaid_amount":           17788500,
  "paid_at":                 null,
  "transaction_count":       1247,
  "refund_count":            18,
  "target_type":             "iban",
  "target_label":            "TR12 **** 3456",
  "bank_reference":          null,
  "sent_at":                 null,
  "deposited_at":            null,
  "hold_reason":             null
}
```

Tutarlar kuruştur. `net_amount = gross_amount − refund_amount − tüm kesintiler`.

| Alan | Açıklama |
|---|---|
| `period_date` | Kapsanan işlem günü |
| `payout_date` | Hesaba geçeceği gün (valör) |
| `credit_card_commission`, `debit_card_commission`, `other_commission` | Kart türüne göre komisyonlar |
| `installment_fee` | Taksit farkı kesintisi |
| `chargeback_deduction` | Ters ibraz kesintisi |
| `subscription_fee` | Paket ücreti |
| `paid_amount`, `unpaid_amount` | Bir çekim talebine bağlanmış / henüz ödenmemiş kısım |
| `target_type`, `target_label` | Ödemenin gideceği hedef (kart ya da IBAN) |
| `bank_reference`, `sent_at`, `deposited_at` | Gönderim ve hesaba geçiş bilgisi |
| `hold_reason` | `on_hold` durumunda bekletme gerekçesi |

## `status`

| Değer | Anlam |
|---|---|
| `estimated` | Valör dolmadı; tutar hâlâ iade/iptale açık, kesinleşmiş sayılmaz |
| `confirmed` | Valör doldu, tutar kesinleşti; gönderim bekliyor |
| `sent` | Karta/bankaya gönderildi; hesaba geçişi teyit edilmedi |
| `deposited` | Bayinin hesabına geçti (terminal) |
| `on_hold` | Operatör bekletti (mutabakat farkı, inceleme); `hold_reason` zorunlu |

Gönderilen hakediş **dondurulur**: sonradan gelen iade eski hakedişi değiştirmez, kendi gününün hakedişine düşer.

## Özet şerit

```bash
curl "https://<cuzdan-adresi>/api/v1/settlements/stats?currency=TRY" \
  -H "Authorization: Bearer $PAYVEN_TOKEN" \
  -H "X-Merchant-Id: $MERCHANT_ID"
```

```json
{
  "currency":        "TRY",
  "paid_total":      150000000,
  "confirmed_total": 17788500,
  "estimated_total": 22000000,
  "on_hold_total":   0,
  "next_payout":     { "date": "2026-10-16T00:00:00.000+03:00", "amount": 17788500, "status": "confirmed" }
}
```

Durum toplamları **ayrı** tutulur; tahmini tutarı kesinleşmiş tutarla toplamayın.

## Hareketler

`GET /settlements/{id}/transactions` hakedişe giren kredi hareketlerini (satışlar) sayfalı döner; "bu ödeme hangi satışlardan geldi" sorusunun cevabıdır.

## Mutabakatla ilişki

Hakediş, Payven ile **bayi** arasındaki hesaptır. Payven ile **banka** arasındaki gün sonu karşılaştırma için [Mutabakat](/sanal-pos/reconciliation/overview) kullanılır.

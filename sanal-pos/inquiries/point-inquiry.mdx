---
title: "Puan Sorgulama"
description: "Bonus, Maximum, World gibi banka programlarının kullanılabilir puan tutarını sorgulayın."
---

Türk bankalarının kart programları (Bonus, Maximum, Axess, World, Paraf, Cardfinans, Wings) müşteriye **puan biriktirme** sunar. Bu uç, mevcut bir işlemin geçtiği banka üzerinden kartın kullanılabilir puan tutarını sorgular.

<Note>
Puan sorgusu **bankaya özgüdür**; her banka desteklemez. İşlemin geçtiği banka desteklemiyorsa `422 POINT_INQUIRY_NOT_SUPPORTED` döner. Desteklenen bankalar için destek ekibinize danışın.
</Note>

## Endpoint

```http
POST /api/v1/payments/{transaction_id}/point-inquiry
```

Gerekli yetki `CanManageTransactions`. `transaction_id`, puan sorgulanacak kartla başlatılmış bir ödeme / 3DS init kaydıdır; sorgu o işlemin geçtiği banka üzerinden yapılır.

## İstek

Kart bilgisi isteğin gövdesinde gönderilir:

```bash
curl -X POST https://vpos.payven.com.tr/api/v1/payments/8e3f5c12-9a7b-4c8d-bc4e-2c963f66afa6/point-inquiry \
  -H "Authorization: Bearer $PAYVEN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "card": {
      "holder_name":  "Test Kullanici",
      "number":       "4546711234567894",
      "expire_month": "12",
      "expire_year":  "2030",
      "cvv":          "000"
    }
  }'
```

| Alan | Tip | Zorunluluk | Açıklama |
|---|---|---|---|
| `card.number` | string | Zorunlu | Kart numarası |
| `card.expire_month` | string | Zorunlu | İki hane (`01`–`12`) |
| `card.expire_year` | string | Zorunlu | İki veya dört hane |
| `card.holder_name`, `card.cvv` | string | Bankaya göre | Bazı bankalar sorgu için ister |
| `extra_properties` | object | Opsiyonel | Bankaya özgü ek alanlar (kart verisi anahtarları yok sayılır) |

## Yanıt

```json
{
  "transaction_id": "8e3f5c12-9a7b-4c8d-bc4e-2c963f66afa6",
  "status":         "three_d_secure_init_processing",
  "is_success":     true,
  "extra_properties": {
    "processed_at":           "2026-05-03T12:34:57.123+03:00",
    "available_point_amount": "125.00"
  }
}
```

| Alan | Açıklama |
|---|---|
| `extra_properties.available_point_amount` | Bankanın bildirdiği kullanılabilir puan tutarı (metin). Banka tutar vermezse `"0"` |
| `extra_properties.processed_at` | Sorgunun işlendiği zaman (`+03:00`) |
| `status` | İşlemin **mevcut** durumu; sorgu durumu değiştirmez |

Puan kullanarak ödeme için Payven'de standart bir alan yoktur; puanla ödeme bankanın kendi akışına bağlıdır.

## Hata yanıtları

| HTTP | `code` | Anlam |
|---|---|---|
| `404` | `PV_TRANSACTION_NOT_FOUND` | İşlem bulunamadı |
| `400` | `invalid_request_body` | Gövde okunamadı |
| `422` | `validation_failed` | `card.number`, `card.expire_month` veya `card.expire_year` eksik |
| `422` | `POINT_INQUIRY_NOT_SUPPORTED` | İşlemin geçtiği banka puan sorgusunu desteklemiyor |
| `422` | `POINT_INQUIRY_FAILED` | Banka puan sorgusunu reddetti (`provider_error_code` bankanın ham kodu) |
| `422` | `POINT_INQUIRY_EXCEPTION` | Sorgu sırasında beklenmeyen hata |

Hata yanıtı RFC 9457 problem+json formatındadır.

## Test ortamı

Test modundaki ya da test kartıyla yapılmış işlemde sorgu bankaya gitmez; başarılı bir yanıt ve `available_point_amount: "0"` döner.

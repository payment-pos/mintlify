---
title: "İşlem Listesi"
description: "Filtreleme ve sayfalama ile işlemleri toplu olarak listeleyin."
---

İşlemlerinizi tarih aralığı, durum, kart, kanal gibi kriterlere göre filtreleyip sayfalı şekilde listeleyin. Liste özet kayıtlar döner; tek bir kaydın ek ayrıntıları için aşağıdaki "Tek bir işlemin detayı" bölümüne bakın.

## Endpoint

```http
GET /api/v1/transactions
```

Gerekli yetki `CanViewTransactions`. İşletme kapsamlı kimlikler yalnız kendi işlemlerini görür; şirket düzeyindeki kimlikler `X-Merchant-Id` başlığıyla tek işletmeye daralır ya da tüm işletmeleri görür.

## Sorgu parametreleri

Tüm parametreler **snake_case**'dir (camelCase `400` ile reddedilir).

| Parametre | Tip | Açıklama |
|---|---|---|
| `page` | int | Sayfa numarası (varsayılan `1`) |
| `page_size` | int | Sayfa başı kayıt (varsayılan `10`) |
| `start_date`, `end_date` | datetime | `created` üzerinde aralık. **`+03:00` ofsetiyle** gönderin (`2026-05-01T00:00:00%2B03:00`); ofsetsiz değer UTC sayılır |
| `status` | enum | `created`, `processing`, `three_d_secure_init_processing`, `three_d_secure_auth_processing`, `authorized`, `capture_processing`, `completed`, `refund_processing`, `refunded`, `canceled_processing`, `canceled`, `failed`, `not_completed`; ayrıca `partially_refunded` (kısmi iadeli `completed` işlemler) |
| `operation_type` | enum | `sale`, `pre_auth`, `post_auth`, `void`, `refund`, `recurring` |
| `payment_type` | enum | `card`, `wallet`, `bkm_express`, `bank_transfer`, `link` |
| `secure_type` | enum | `non3_d`, `three_d_sv1`, `three_d_sv2`, `three_d_pay` |
| `card_schema_type` | enum | `visa`, `master_card`, `amex`, `troy`, `union_pay`, `proprietary` |
| `card_type` | enum | `credit`, `debit`, `prepaid` |
| `installment_type` | enum | `single` (peşin) veya `installment` (taksitli) |
| `installment_count` | int | Tam taksit sayısı |
| `bin_number` | string | Kartın ilk 1–6 hanesi |
| `masked_card_number` | string | Maskeli kart numarasında içerir araması (ör. son 4 hane) |
| `card_token` | string | Kayıtlı kart token'ı (tam eşleşme) |
| `min_amount`, `max_amount` | int (kuruş) | Tutar aralığı |
| `merchant_id` | UUID | İşletme filtresi |
| `external_merchant_id` | string | Sizin işletme kimliğinizle filtre |
| `basket_id` | string | Sepet kimliği |
| `payment_link_id` | UUID | Yalnız bu ödeme linkinden gelen işlemler |
| `source_channels` | enum[] | Tekrarlanan parametre (`?source_channels=api&source_channels=payment_link`): `api`, `portal`, `hosted_checkout`, `payment_link`, `recurring`, `ai_assistant` |
| `connector_code` | string | Banka konnektör kodu |
| `connector_configuration_id` | UUID | Konnektör konfigürasyonu |
| `error_code` | string | Başarısız işlemin son hata kodu (Payven kodu ya da banka ham kodu) |
| `buyer_name`, `buyer_surname` | string | Alıcı adı / soyadında içerir araması |
| `search_term` | string | `id`, `basket_id`, `external_id`, maskeli kart, alıcı adı ve kart token'ı üzerinde içerir araması |
| `sort_by` | string | `created` (varsayılan), `amount`, `status`, `operation_type`, `completed_at` |
| `sort_dir` | string | `desc` (varsayılan) veya `asc` |

## İstek

```bash
curl "https://vpos.payven.com.tr/api/v1/transactions?start_date=2026-05-01T00:00:00%2B03:00&end_date=2026-05-31T23:59:59%2B03:00&status=completed&page_size=50" \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

## Özet ve kırılım

Aynı filtrelerle (sayfalama hariç) iki toplu uç vardır:

| Uç | Ne döner |
|---|---|
| `GET /api/v1/transactions/summary` | Filtreye uyan **tüm** işlemlerin adet ve tutar özeti |
| `GET /api/v1/transactions/breakdown?group_by=day` | Tek boyutta kırılım: `day`, `merchant`, `error_code`, `card_brand`, `connector` |

## Tek bir işlemin detayı

Listedeki bir kaydın `id` değeriyle:

```bash
curl https://vpos.payven.com.tr/api/v1/transactions/8e3f5c12-9a7b-4c8d-bc4e-2c963f66afa6 \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

Detay yanıtı liste alanlarına ek olarak `ip_address`, 3DS doğrulama alanları (`cavv`, `eci`, `xid`, `md`, `three_ds_server_trans_id`), `provider_raw_request`, `provider_raw_response`, ödemeye ait `webhook_deliveries[]` ve yönlendirme kararını (`routing_decision`) taşır. Durum geçişleri için [İşlem Geçmişi](/sanal-pos/inquiries/payment-history).

## Dışa aktarma

Liste filtreleriyle birebir aynı parametreleri alan CSV dışa aktarma ucu vardır:

```http
GET /api/v1/transactions/export?scope=all&status=completed
```

`scope=all` (varsayılan) tüm filtreli kayıtları akıtır; `scope=page` yalnız `page` / `page_size` penceresini verir. Kolon şeması `GET /api/v1/transactions/export/schema` ucundadır.

## Hata yanıtları

| HTTP | `code` | Anlam |
|---|---|---|
| `400` | — | Sorgu parametresi `camelCase` ya da biçimi geçersiz |
| `403` | `forbidden` | `CanViewTransactions` yetkisi yok |
| `422` | `validation_failed` | Filtre tutarsız (ör. `installment_type=single` ile `installment_count > 1`) |

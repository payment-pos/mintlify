title: "Alıcı Hesapları"
description: "Transferlerin hedef hesap kayıtları (IBAN, hesap numarası, kart) ve doğrudan hesap yönetimi."
---

Alıcı hesabı (receiver account), bir transferin **hedef hesabını** tutan kayıttır: hesap sahibi adı, banka ve IBAN / hesap numarası / kart bilgisi. İki şekilde oluşur:

- **Otomatik:** `POST /transfers/bulk/create` her kalem için istekteki alıcı bilgisinden yeni bir alıcı hesabı kaydı açar ve transfere bağlar (`receiver_account_id`).
- **Elle:** `POST /receiver-accounts` ile önceden hesap tanımlarsınız.

Bir hesap isteğe bağlı olarak bir [alıcıya](/para-transferi/recipients/overview) bağlanır (`recipient_id`); böylece bir alıcının birden çok hesabı listelenebilir.

```
Alıcı (Recipient)
└── Alıcı Hesapları (Receiver Accounts)
    ├── IBAN — Garanti BBVA — "Maaş hesabı"
    ├── IBAN — Akbank — "Prim hesabı"
    └── IBAN — İş Bankası — "Vergi hesabı"
```

<Note>
Transfer oluştururken hedef hesap her zaman istekte `recipient.iban` (ya da kart bilgisi) ile verilir; `receiver_account_id` ile mevcut bir hesap kaydını **referans vermek** mümkün değildir. Alıcı hesapları listeleme, raporlama ve alıcı yönetimi içindir.
</Note>

## Endpoint'ler

```http
POST   /api/v1/receiver-accounts                                 # Yeni hesap
GET    /api/v1/receiver-accounts                                 # Liste (sayfalı)
GET    /api/v1/receiver-accounts/by-bank/{bank_id}               # Banka bazlı liste
GET    /api/v1/receiver-accounts/by-saved-account/{recipient_id} # Alıcıya bağlı hesaplar
PUT    /api/v1/receiver-accounts/{id}                            # Güncelle (tam değiştirme)
DELETE /api/v1/receiver-accounts/{id}                            # Sil
```

**Yetki:** okuma `CanViewRecipients`; oluşturma, güncelleme, silme `CanManageRecipients`.

## Hesap oluşturma

```bash
curl -X POST https://transfer.payven.com.tr/api/v1/receiver-accounts \
  -H "Authorization: Bearer $PAYVEN_TOKEN" \
  -H "Idempotency-Key: receiver-account-ahmet-akbank" \
  -H "Content-Type: application/json" \
  -d '{
    "bank_id":      "5e0b0f2a-0000-0000-0000-000000000002",
    "recipient_id": "abc12345-0000-0000-0000-000000000000",
    "holder_name":  "Ahmet Yılmaz",
    "iban":         "TR330006100519786457841326",
    "description":  "Maaş hesabı"
  }'
```

| Alan | Tip | Zorunluluk | Açıklama |
|---|---|---|---|
| `bank_id` | UUID | Zorunlu | [Banka kataloğundaki](/identity/lookups/banks) banka kimliği |
| `recipient_id` | UUID | Opsiyonel | Bağlı alıcı |
| `holder_name` | string | Zorunlu | Hesap sahibi adı (en fazla 200 karakter) |
| `iban` | string | Opsiyonel | En fazla 34 karakter; **biçim ve mod-97 sağlaması doğrulanır** |
| `account_number` | string | Opsiyonel | En fazla 50 karakter |
| `masked_card_no`, `card_token` | string | Opsiyonel | Kartlı hesap (en fazla 20 / 500 karakter) |
| `description` | string | Opsiyonel | Etiket (en fazla 500 karakter) |

Yanıt `201 Created`, gövde yeni hesabın kimliğidir (UUID string).

## Listeleme

```bash
curl "https://transfer.payven.com.tr/api/v1/receiver-accounts?recipient_id=abc12345-...&page_size=50" \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

Standart sayfalı liste döner; her kayıt:

```json
{
  "id":             "ra-8e3f5c12-...",
  "bank_id":        "5e0b0f2a-0000-0000-0000-000000000002",
  "recipient_id":   "abc12345-0000-0000-0000-000000000000",
  "holder_name":    "Ahmet Yılmaz",
  "iban":           "TR330006100519786457841326",
  "account_number": null,
  "masked_card_no": null,
  "card_token":     null,
  "description":    "Maaş hesabı",
  "bank_name":      "Akbank",
  "bank_code":      "00046"
}
```

`bank_code` 5 haneli TCMB kodudur. Filtreler: `bank_id`, `recipient_id`, `search_term`, `include_inactive`.
`by-saved-account/{recipient_id}` ve `by-bank/{bank_id}` aynı sayfalı yapıyı döner (yol parametresi ilgili filtreyi doldurur).

## Güncelleme ve silme

`PUT /receiver-accounts/{id}` kaydı **tam olarak değiştirir** (gönderilmeyen alanlar boşalır); gövde oluşturma gövdesiyle aynıdır, yanıt `200` ve hesap kimliğidir. `DELETE` `204` döner. Geçmiş transferlerin `receiver_account` bilgisi etkilenmez.

## Hata response'ları

| HTTP | `code` | Anlam |
|---|---|---|
| `404` | `resource_not_found` | `id` ya da `bank_id` bulunamadı |
| `422` | `validation_failed` | IBAN biçimi / sağlaması geçersiz ya da alan sınırı aşıldı — `errors[]` ile detay |
| `403` | `forbidden` | `CanManageRecipients` izni yok |

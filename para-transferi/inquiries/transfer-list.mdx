title: "Transfer Listesi"
description: "Filtreleme ve sayfalama ile transferleri toplu olarak listeleyin."
---

Transferlerinizi tarih, durum, tip, hesap, alıcı gibi kriterlere göre filtreleyip sayfalı şekilde listeleyin. Liste ve detay aynı [Transfer Objesi](/para-transferi/transfer-object) şemasını döner; detaya özgü alanlar (`events`, `webhook_deliveries`, `channel_suggestions`) listede boş gelir.

## Endpoint

```http
GET /api/v1/transfers
```

**Yetki:** `CanViewTransfers`. Bayi kapsamlı kimlikler yalnız kendi bayilerinin transferlerini görür; `tenant-*` rolleri bayi başlığıyla daraltabilir.

## Sorgu parametreleri

Tüm parametreler **snake_case**'dir (camelCase `400` ile reddedilir).

| Parametre | Tip | Açıklama |
|---|---|---|
| `page` | int | Sayfa numarası (varsayılan `1`) |
| `page_size` | int | Sayfa başı kayıt (varsayılan `10`; `0` = tümü, en fazla 5.000 kayıt) |
| `external_id` | string | Sizin referansınızla **birebir** eşleşme (oluştururken verdiğiniz `external_id`) |
| `request_id` | string | Oluşturma isteğinde gönderdiğiniz `X-Request-Id` (paket numaranız) ile **birebir** eşleşme — paketin tüm transferlerini döner |
| `bulk_transfer_batch_id` | UUID | Toplu transfer paketi kimliği |
| `unsettled` | bool | `true`: bankaya gönderilmiş ama **30 dakikadan uzun süredir** sonucu kesinleşmemiş (`processing` / `delivered`) transferler |
| `unresolved` | bool | `true`: otomatik takibin kesinleştiremediği transferler — 30 dakikayı aşmış `processing` ve 3 günü aşmış `delivered` |
| `status` | enum | `pending`, `awaiting_funds`, `approved`, `rejected`, `processing`, `delivered`, `completed`, `failed`, `refunded` |
| `transfer_type` | enum | `fast`, `eft`, `remittance`, `credit_card` (talep edilen tip) |
| `from_date`, `to_date` | datetime | Tarih aralığı (ISO 8601, `+03:00` ile gönderin) — `scheduled_date` üzerinde filtreler |
| `min_amount`, `max_amount` | long (kuruş) | Tutar aralığı |
| `connector_account_id` | UUID | Gönderici hesap filtresi (talep edilen ya da gerçekleşen) |
| `receiver_account_id` | UUID | Alıcı hesap filtresi |
| `search_term` | string | `external_id`, `request_id`, açıklama ve alıcı adı üzerinde "içerir" araması (en fazla 100 karakter) |
| `group_splits` | bool | `true`: parçalı ödemenin parçaları tek satıra indirgenir ve satır `split_group` taşır (varsayılan `false`: parça parça listelenir) |
| `include_inactive` | bool | Pasif kayıtları da getirir |

<Note>
`external_id` / `request_id` **birebir** eşleşir ve indekslidir — kendi kaydınızı bulmak için bunları
kullanın. `search_term` ise "içerir" araması yapar; ekran araması içindir, entegrasyon mantığına
bağlamayın.
</Note>

## İstek

```bash
curl "https://transfer.payven.com.tr/api/v1/transfers?from_date=2026-05-01T00:00:00%2B03:00&to_date=2026-05-31T23:59:59%2B03:00&status=completed&transfer_type=fast&page_size=50" \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

## Filtreleme örnekleri

**Kendi referansınızla tek transfer:**

```http
GET /api/v1/transfers?external_id=PAYROLL-001
```

**Bir paketin (`X-Request-Id`) tüm transferleri — webhook kesintisinde yedek sorgu:**

```http
GET /api/v1/transfers?request_id=PAYROLL-2026-05&page_size=100
```

**Toplu transfer paketinin kalemleri:**

```http
GET /api/v1/transfers?bulk_transfer_batch_id=4b6f2c1e-...&page_size=100
```

**Sonucu 30 dakikadan uzun süredir kesinleşmemiş transferler:**

```http
GET /api/v1/transfers?unsettled=true
```

Bu listedeki transferler **yeniden gönderilmemelidir**; sonuç otomatik ya da operatörce kesinleşir.
Kesinleştirme yolları: [Belirsiz Sonuç ve İade](/para-transferi/transfers/outcome-resolution).

**Bugün başarılı tamamlanan tüm FAST transferleri:**

```http
GET /api/v1/transfers?from_date=2026-05-03T00:00:00%2B03:00&to_date=2026-05-03T23:59:59%2B03:00&status=completed&transfer_type=fast
```

**100.000 TL üzeri başarısız işlemler:**

```http
GET /api/v1/transfers?status=failed&min_amount=10000000
```

## Özet sayılar

```http
GET /api/v1/transfers/stats?from_date=2026-05-01T00:00:00%2B03:00&to_date=2026-05-31T23:59:59%2B03:00
```

Tüm filtreye uyan kayıtlar için durum kovalarına göre `count` ve `total_amount` döner
(`pending`, `approved`, `processing`, `error`, `completed` (= `completed` + `delivered`), `refunded`,
`today_completed`) ve genel `total` / `total_amount` içerir. Sayfa bazlı toplama yerine bunu kullanın.

## Export

`GET /api/v1/transfers/export` aynı filtrelerle CSV (UTF-8 BOM, Excel uyumlu) döner: `scope=page`
istekteki sayfayı, `scope=all` (varsayılan) tüm filtreli kayıtları indirir. Kolon şeması
`GET /api/v1/transfers/export/schema` ile alınır.

## Hata response'ları

| HTTP | `code` | Anlam |
|---|---|---|
| `400` | `invalid_query_parameter` | Sorgu parametre adı snake_case değil (ör. `pageSize`) |
| `403` | `forbidden` | `CanViewTransfers` izni yok |
| `422` | `validation_failed` | Değer doğrulaması başarısız (ör. `search_term` > 100 karakter) |
